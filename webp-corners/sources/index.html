webp-corners: sources

Real encoder output, not assembled. The partition count lives inside the bool-coded partition 0, so no case can write it; these lossy frames carry 1, 2, 4 and 8 token partitions, made through the encoder API by make_partition_sources.c because cwebp emits only one.

Seven files in files/ come from these: the four as they are, and three with the partition-size table rewritten to lie about what follows it. The notes say what each one does.
