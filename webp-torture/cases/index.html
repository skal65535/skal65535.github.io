webp-torture cases

189 text cases, each assembled into the .webp of the same name in files/. A case names the fields the specification names — RFC 6386 for the lossy frame, RFC 9649 for the container — and carries its own note on what it is for; the notes have the full write-up. reject means a conforming decoder must refuse it.
